# FrenchDays

Небольшой браузерный тренажёр для запоминания дней недели на французском языке.

## Live

- GitHub Pages: <https://polpal1623.github.io/FrenchDays/>
- Репозиторий: <https://github.com/PolPal1623/FrenchDays>

## Что внутри

- 7 раундов без повторов: за одну сессию проходят все дни недели.
- Два типа заданий: ввод ответа и выбор правильного варианта.
- Светлая и тёмная тема с сохранением выбора.
- Таблица-справочник по всем дням недели с транскрипцией.
- Личный рекорд в `localStorage`.

## Запуск

1. Откройте `index.html` в браузере.
2. Сборка и зависимости не нужны.

## Редактирование

- Словарь находится в массиве `DAYS` внутри `index.html`.
- Количество раундов автоматически берётся из длины словаря.
- Интерфейс оформлен в общем стиле French Learning Suite.
